# Nothando Vimbai — Personal Profile Page

This is my personal profile page that I built for the Web Technologies (CIS2103) 
Unit II assignment at Africa University. It is a one-page site that includes 
an About section, my skills, a project I have worked on, and a contact form.

## Accessibility Issue and Fix

During the Unit II practical session my peer reviewer pointed out that my nav 
links were not working. When you clicked "About" or "Skills" nothing happened. 
This was because my sections were missing id attributes so the links had nothing 
to jump to. I fixed this by adding id="about", id="skills", id="projects" and 
id="contact" to each section so the navigation now works properly.
